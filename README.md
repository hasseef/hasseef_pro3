# منصة حصيف – HASSEEF Platform

هذا المستودع يحتوي على حزمة متكاملة كبداية (Starter) لمنصة حصيف:

- `frontend/` – واجهات HTML/Tailwind جاهزة للمنصة (الصفحة الرئيسية + لوحات الحسابات + صفحات الخدمات).
- `backend/` – سكافولد (Scaffold) للـ API باستخدام Node.js و Express، مع نماذج مبدئية للحلول والمشاريع والتمويل.

يمكن رفع هذا المجلد كما هو إلى GitHub ومشاركته مع فريق التطوير لاستكمال البناء (قاعدة البيانات، الصلاحيات، الربط مع الواجهات، النشر على خادم فعلي).
