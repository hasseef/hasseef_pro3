# منصة حصيف – Hasseef Platform (Frontend Starter)

هذا المستودع يحتوي على حزمة جاهزة لواجهة منصة حصيف، يمكن رفعها مباشرة إلى GitHub
واستخدامها كنقطة انطلاق لفريق التطوير البرمجي (Back-end / Database / APIs).

## محتويات المجلد

- `index.html`  
  الصفحة الرئيسية (Landing / Overview) كما صمّمها المصمم، مع هوية حصيف.

- `pages/`  
  مجموعة صفحات تمهيدية جاهزة لكل نوع من أنواع الحسابات والخدمات، منها:
  - `dashboard_emirate.html` – لوحة تحكم الإمارة
  - `dashboard_nonprofit.html` – لوحة تحكم القطاع غير الربحي
  - `solutions.html` – واجهة إدارة الحلول
  - `projects.html` – واجهة إدارة المشاريع
  - `events.html` – واجهة إدارة الفعاليات
  - `funding.html` – واجهة إدارة التمويل
  - `vision2030.html` – ربط برؤية المملكة 2030
  - `impact_reports.html` – تقارير الأثر

## طريقة الاستخدام

1. أنشئ مستودع جديد في GitHub (مثلاً: `hasseef-platform`).
2. ارفع جميع الملفات والمجلدات الموجودة في هذه الحزمة إلى المستودع.
3. يمكن استخدام GitHub Pages لعرض الواجهة مباشرة، أو ربط هذا الfrontend مع Back-end
   (Node.js, Laravel, Django, أو أي إطار عمل يختاره فريق التطوير).
4. يمكن للمطورين تطوير كل صفحة لتصبح لوحة تشغيل حقيقية مرتبطة بقاعدة بيانات وواجهات برمجية (APIs).

## ملاحظة

هذه الحزمة تمثل واجهة أولية (Prototype / Frontend Starter)، وهي منسجمة مع النقاشات
التشغيلية والتقنية حول منصة حصيف، لكنها لا تحتوي على منطق عمل (Business Logic) أو قاعدة بيانات.
هذه الأجزاء تتم إضافتها من قبل مهندس البرمجيات أو فريق التطوير.
